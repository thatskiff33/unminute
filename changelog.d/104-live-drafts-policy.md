- **IT can turn off draft text while recording.** A new policy, `AllowLiveDrafts`, is in the administrative template. The feature it governs (rough text of what is said while a meeting is recorded, kept in memory only and replaced by the full transcript) is not available in the app yet; when it arrives it will be off unless the user turns it on. With the policy set to 0 it cannot be turned on (#104).
