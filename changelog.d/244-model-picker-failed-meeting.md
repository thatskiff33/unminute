- **Settings marks speech models that are not ready.** Settings > Speech model labels a model "(not downloaded)" or "(damaged)", as the Downloads page does. Choosing one still saves the choice, and a note beside the picker says how to download or repair it.
- **A failed meeting can switch speech model.** A meeting that stopped (for example because its model is not downloaded) offers **Transcribe with another model…**, which transcribes it again with the model now chosen in Settings; parts already finished are kept as an earlier version. Transcribe again in the Versions tab works for it too. A chosen model that is not ready is refused with a pointer to Manage downloads, before anything changes.
- **Model errors point to Manage downloads.** Messages about a missing or damaged model now say Settings > Manage downloads instead of Setup.
