- **Security update: Pillow 13.0.0 and certifi 2026.10.19** (were 12.3.0 and 2026.5.20). Pillow 13.0.0 fixes eight advisories in its image readers and writers (TIFF, GIF, PPM, EPS and PDF append: CVE-2026-112395, CVE-2026-112397, CVE-2026-112400, CVE-2026-112404, CVE-2026-112895, CVE-2026-112896, CVE-2026-112897, CVE-2026-112899). Pillow is bundled only because matplotlib, which the speaker identification library depends on, needs it; Unminute never opens an image with it, so exposure was nil in practice. certifi 2026.10.19 removes the `emSign ECC Root CA - G3` root certificate from its bundle (PYSEC-2026-4320, GHSA-6q48-6c7w-9gw2). Model downloads check certificates against the Windows certificate store first and fall back to that bundle, so a site whose certificate chained to that root could still have been trusted; every downloaded file is still checked against its pinned SHA-256 before use. Both updates were taken inside the usual 7-day wait for new versions, as a security exception. Nothing changes in how Unminute works.
