Security hardening (#111, phase B):

- **For IT: offboarding a person who leaves.** Run as the user, `runtime\python.exe -I -B -X disable-remote-debug -m workspace --offboard-report` lists, as counts and yes or no only, what Unminute keeps for them, and `--offboard` removes it with the app closed: the workspace with its logs and audit log, the downloaded models and the remembered Hugging Face token. It removes nothing while a meeting, retention hold, unfinished cleanup, recording or meeting audio is left, so meeting content is still only deleted through the app's own confirmed steps. It puts the lid setting back, records an `offboarded` entry in the audit log and the Windows event log, and erases the workspace's key before deleting anything, so a removal that stops part-way leaves nothing that can be opened; running it again finishes the job. Anything else in the data folder, such as a workspace set aside after damage, is left alone and counted, and the command then ends with exit code 4 rather than reporting a clean removal. It does not look at anything version 0.4.3 or earlier left. It refuses to run as Local System, while the app is open, or when the data folder is a link to somewhere else. A plain uninstall still keeps the data. See `docs/IT_DEPLOYMENT.md`, "Offboarding".
