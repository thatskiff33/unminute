- **Security update: filelock 4.2.4** (was 3.29.1). It fixes three advisories (CVE-2026-112940, CVE-2026-112913 and CVE-2026-112907): another account on the same computer could interfere with filelock's SQLite-based reader and writer lock, or hold up a "soft" lock on Windows. filelock is used by the model download and by the speech and speaker identification libraries to coordinate access to model files. Unminute's own code does not call it, none of its libraries uses the reader and writer lock, and the model folder is in your own profile, which other standard accounts cannot open, so exposure was nil in practice. setuptools also moves to 84.2.1 (was 84.0.0) for GHSA-xmj3-9gf7-h52w; it is removed from the package when it is built, so it never reaches your computer. Both updates were taken inside the usual 7-day wait for new versions, as a security exception. Nothing changes in how Unminute works.
