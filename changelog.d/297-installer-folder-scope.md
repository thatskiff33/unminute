Security hardening (#111):

- **The installer only removes what it installed.** An update used to remove every folder in the install folder's `versions` folder except the current and previous versions, so an `-InstallDir` that already held an unrelated `versions` folder (a shared folder or a drive's root) could lose its contents. The installer now refuses, with exit code 2 and before writing anything, an install folder that is not new, empty or an Unminute install, or that holds a link or junction where it would look; an install that stopped before it finished can still be completed by running it again. It removes only version folders it made, never through a link, and leaves anything else in place. A `current.json` makes the folder an install only when it names a valid version, so another program's file of that name does not. The uninstaller, too, never removes through a link or junction: it stops if one is at its own entries, and removes one inside a version as a link. The package's version and the values in `current.json` must be plain version names before they are used as folder names, so a damaged or altered value cannot lead outside the install folder; `-Rollback` refuses one (#297).
