- **Whisper large-v3 can be downloaded.** Setup (under Other options) and Settings > Manage downloads now offer Whisper large-v3, a 3.09 GB download that is checked file by file like the other models. OpenAI rates it its most accurate Whisper model. In our earlier tests, which ran an OpenVINO build of it on Intel Arc graphics rather than the app's processor engine, it was no more accurate than turbo and needed about twice the memory. It is the largest model, so expect it to be the slowest on a processor. Before, Settings let you choose it but nothing could download it, so a meeting set to it could not run on a new install. Parakeet v2 stays the recommended model, and Whisper large-v3 turbo the quicker Whisper option.
