- **Whisper large-v3 can be downloaded.** Setup (under Other options) and Settings > Manage downloads now offer Whisper large-v3, a 3.09 GB download that is checked file by file like the other models. OpenAI rates it its most accurate Whisper model, but in our tests it was no more accurate than turbo, needed about twice the memory and was the slowest on a processor. Before, Settings let you choose it but nothing could download it, so a meeting set to it could not run on a new install. Parakeet v2 stays the recommended model, and Whisper large-v3 turbo the quicker Whisper option.
