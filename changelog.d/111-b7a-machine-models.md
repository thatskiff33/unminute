Security hardening (#111, slice B7a):
- **A machine install uses the models your IT team installs first.** Where Unminute is installed for everyone on the computer, models IT places under `%ProgramFiles%\Unminute\models` (which only administrators can change) are used before any copy in a user's own profile. The app checks them against the record IT's install step writes, or every file's checksum, and never changes them. Downloads shows such a model as "Installed by your IT team.", with nothing to download, repair or remove.
- **New policy: `AllowUserModels`.** Machine installs only. Set to 0, the app uses only the models IT installed, and refuses model downloads, which would not be used; Setup and Downloads show "Ask your IT team" in place of Download or Repair. If the policy cannot be read, the app behaves as if it were 0. Per-user installs ignore it. The graphics card components are not models, so the app still accepts their download, but Downloads shows "Ask your IT team" for them too while this is 0.
- **The package's model list says where IT's copy goes.** `model-manifest.json` in each package now gives each model's folder and credit, for preparing IT's copies.
