- **The licence texts now cover code compiled into other libraries.** The package's third-party notices list, for each package, the code from other projects built into its libraries, with that code's licence texts in the package: the Rust crates in cryptography, hf-xet, tokenizers and safetensors (one file of texts for each package), OpenSSL, Intel oneMKL, oneDNN, NVIDIA's CUDA runtime and others in CTranslate2, LibYAML, libffi, pybind11, and the libraries SciPy bundles. Nothing in the notices says texts are still to follow. A release build stops if a package's bill of materials names a Rust crate with no text (#176).
