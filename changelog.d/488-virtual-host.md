Security hardening (#111):
- **The window's page has an address of its own.** The window now shows its page at `https://unminute.invalid/index.html`, which WebView2 serves itself from the app's own page folder and nothing else, instead of a `file://` address (#488). Pages and sites of any other origin cannot load the page's files, the page cannot start background workers, the window still refuses to go anywhere else (every `file://` address included), and if WebView2 cannot set the address up, the window closes rather than open the page. The address is not on the network: there is no DNS lookup or connection for it, and nothing listens on the computer. Nothing changes in how you use the app.
