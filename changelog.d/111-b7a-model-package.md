Security hardening (#111, slice B7a):
- **IT can install the models for everyone on a computer.** On a machine install, IT downloads the models once with Unminute's Setup, then builds a model package with `tools\intune\New-ModelPackage.ps1` from the release it verified: the script checks every model file against that release's own list, uses no network, and writes the Intune settings beside the package. Intune runs the package's `Install-Models.ps1` as SYSTEM, which checks every file again and installs the models into `%ProgramFiles%\Unminute\models`. Staff then need no download and no Hugging Face token. A model folder in use is left for Intune to retry. Details are in the IT guide, "Models for everyone".
- **The package credits the speaker model.** Its `LICENCES.txt` gives each model's licence and source, and for the speaker model the pyannoteAI credit, the CC BY 4.0 licence link, a statement that the files are unmodified and the three citations on its model card. IT accepts the speaker model's Hugging Face conditions with its own account when it downloads; staff accept nothing.
- **The machine uninstall removes those models too.** The installer keeps them through updates.
