Security hardening (#111):

- **Speaker identification takes fewer library folders from the environment.** When speaker identification loads, PyTorch and TorchCodec add folders named by `PYTHONUSERBASE`, `NVTOOLSEXT_PATH` and `CUDA_PATH_V*`, folders under `ProgramFiles`, and the folder of any `ffmpeg` on `PATH`, to the places Windows looks for libraries. Unminute's worker processes now remove those variables, set `ProgramFiles` to the real Program Files folder as Windows records it, and keep `ffmpeg` off their `PATH` before these libraries load, on the graphics card or the processor. PyTorch's NVIDIA and CUDA folders under Program Files can then only be changed with administrator rights. Python's default per-user library folder (`%APPDATA%\Python\Library\bin`, which follows `APPDATA`) is still searched when it exists, a known limit recorded in the security model. Nothing else changes for users (#358).
