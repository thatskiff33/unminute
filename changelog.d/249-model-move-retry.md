- **Downloading or repairing a model waits for a file that is in use for a moment.** Antivirus software such as Microsoft Defender can open newly downloaded files for a moment to scan them, and Windows then refuses to move the verified download into place, so a download could fail at the last step and need starting again. Moving the verified files into place (and a damaged copy aside), for speech and speaker models and the graphics card component, now tries again for up to 30 seconds when Windows refuses it as access denied or in use, then fails with the same message as before. Any other error still fails at once, and nothing else is moved or deleted (#249).
