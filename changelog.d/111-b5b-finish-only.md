Security hardening (#111):

- **Graphics card components an update no longer uses are removed.** When an update of Unminute moves to a newer graphics card component, the copy that no installed version uses any more is removed by itself, a minute after start-up, freeing a few gigabytes. Nothing is removed while a download or check is running, while Unminute is also installed for the whole computer, or after updating from a version before this one, which does not say which components it uses.
- **Each version is checked the first time it opens.** After an install, an update or a repair, the first start takes a few seconds longer while the version checks that it can run on this computer: its modules and WebView2 load, the network guard holds and Windows can protect a key for you. On a new Windows profile the second start is checked too. A check that is slow while antivirus software scans the new files is run once more before it counts as failed, so a version that does not answer at all holds the start for about a minute before its message shows. If the version itself fails, the previous version opens instead when it uses the same workspace format, with a message naming IT and a code; otherwise the message shows and nothing opens. Repairing or reinstalling the version lets it be checked again.
- **Groundwork for the machine-wide install (for IT).** Where IT installs Unminute for the whole computer (a later version), each version is checked the first time it opens for a user, and a version that fails opens another kept version instead, with a message naming IT and a code. An update that changes how the workspace is stored runs a full self-test first and never migrates after a failed check. Like the worker processes, the self-test removes `HIP_PATH` before Whisper's libraries load (#357). While a user's workspace still holds meetings, the version kept for it opens in finish-only mode, with a banner and at most one message a day: review, hand off and clean up, but no new recordings or imports. `--health` reports `slot`, `update_waiting` and `self_check`.
