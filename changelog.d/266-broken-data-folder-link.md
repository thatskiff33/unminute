- **A data folder link whose folder is missing now gets a message.** If `%LOCALAPPDATA%\Unminute`, or its `workspace` folder, is a junction or link to a folder that no longer exists, Unminute closed at start without saying why. It now says the workspace folder is linked to a missing folder and asks the user to contact IT, without naming a folder. `--status` gives the same message, `--health` reports `location`, and the installer's workspace check stops with exit code 6 and the same message. This includes a chain of links and a target written as a volume name or with the `\?\` prefix, and nothing is created where the link points (#266).
