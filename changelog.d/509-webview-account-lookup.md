- **Closing the window no longer lets WebView2 look up your Windows account.** On a PC signed in with a work or Microsoft account, the Microsoft Edge WebView2 Runtime could load Microsoft's sign-in library while the window closed, ask Windows for the account and its tokens, and leave an account cache and Internet Explorer cache files in your profile. Unminute now ends the window's WebView2 process itself once a close goes ahead, so that shutdown never runs. A Windows shutdown or sign-out still closes it as before, so a cancelled shutdown leaves the window working. The window's private browsing data is still removed on close.
