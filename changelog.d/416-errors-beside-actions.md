- **Errors stay beside the action that caused them.** On Import a recording, Hand off, each Settings card, Downloads and Setup's download steps, a message that something could not be done now appears next to the button or switch you used, and stays until you select **Dismiss** or the action works, instead of disappearing from the corner after 8 seconds. Other errors still show briefly at the bottom right, now with an alert mark; confirmations keep their tick.
- **How a message looks no longer depends on its wording.** The app now says whether each refusal is an error or information, and the window styles it by that, so rewording a message cannot make an error look like a success. A copy that worked but could not open the browser is no longer shown as a plain success.
- **A task-focused user guide.** The guide now starts with what you will do and how errors show, keeps reference material after the tasks, and moves the list of what is not in a release yet to the README. It describes the path where IT installs the models, with no download or Hugging Face token for staff, and the IT guide says what staff see then.
