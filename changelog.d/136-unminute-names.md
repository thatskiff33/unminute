- **One name everywhere: Unminute.** The app's data is now in `%LOCALAPPDATA%\Unminute` (`workspace` and `models`), it installs to `%LOCALAPPDATA%\Programs\Unminute`, and its uninstall entry, taskbar identity, saved Hugging Face token and icon use the Unminute name (#136).
- **Not an update in place from 0.4.3 or earlier.** Nothing carries over, and this version starts with an empty workspace. First, in the version you have: hand off or copy anything you still need, confirm the cleanup of finished meetings, check any holds with whoever manages them, and remove the Hugging Face token in Setup. Then uninstall it in Settings > Apps, install this version, download the models again in Setup and enter the token again. The earlier version's workspace and models stay in their own folders until you delete them (docs/PACKAGING.md, "Updates", says where). A token left behind can still be removed in Windows Credential Manager, under Windows Credentials. If you install this version first, Settings > Apps shows two Unminute entries, and uninstalling the earlier one afterwards removes the new Start menu shortcut: install this version again to restore it, and pin it again in place of any old taskbar pin (#136).
- **For IT: a new uninstall key.** Intune detection now uses `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Unminute` (see docs/PACKAGING.md), so the earlier version's Win32 app still counts as installed: supersede it with the option to uninstall the previous version, or deploy its uninstall first. Have users finish the steps above in the earlier version (hand off, cleanup, holds, token) before that uninstall runs, and add `-Managed` to this release's install command if the earlier one used it, as the setting does not carry over (#136).
- **Safer uninstall.** The installer and the uninstaller refuse an install folder that is, holds or sits inside `%LOCALAPPDATA%\Unminute`, an empty one, or one starting with `\\` or `//`. The uninstaller removes only what the installer put in its folder, and removes nothing if the folder holds anything else or is not an Unminute install, so a mistyped folder cannot take the real install's shortcut and uninstall entry (#136).
