- **One name everywhere: Unminute.** The app's data is now in `%LOCALAPPDATA%\Unminute` (`workspace` and `models`), it installs to `%LOCALAPPDATA%\Programs\Unminute`, and its uninstall entry, taskbar identity, saved Hugging Face token and icon use the Unminute name. Nothing carries over from an earlier install: uninstall that first, then install this version, download the models again in Setup and enter the token again. The earlier install's data stays in its own folders until you delete them (#136).
- **For IT: a new uninstall key.** Intune detection now uses `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Unminute` (see docs/PACKAGING.md). The installer also refuses an install folder that is, holds or sits inside `%LOCALAPPDATA%\Unminute`, because uninstalling deletes the install folder (#136).
