- **One name everywhere: Unminute.** The app's data is now in `%LOCALAPPDATA%\Unminute` (`workspace` and `models`), it installs to `%LOCALAPPDATA%\Programs\Unminute`, and its uninstall entry, taskbar identity, saved Hugging Face token and icon use the Unminute name (#136).
- **Not an update in place from 0.4.3 or earlier.** Nothing carries over, and this version starts with an empty workspace. First, in the version you have: hand off or copy anything you still need, confirm the cleanup of finished meetings, check any holds with whoever manages them, remove the Hugging Face token (Settings > Manage downloads > Remove the remembered token), and note your settings and watched folders and copy any handoff template you edited or wrote. Then uninstall it in Settings > Apps, install this version, download the models again in Setup and enter the token again, and set up your settings, templates and watched folders again (leave "Also import recordings already in it" unticked, so finished recordings are not imported twice) and, if you used it, the graphics card component. The earlier version's workspace and models stay in their own folders until you delete them (docs/PACKAGING.md, "Updates", says where). A token left behind can still be removed in Windows Credential Manager, under Windows Credentials. If you install this version first, Settings > Apps shows two Unminute entries, and uninstalling the earlier one afterwards removes the new Start menu shortcut: install this version again to restore it, and pin it again in place of any old taskbar pin (#136).
- **For IT: a new uninstall key.** Intune detection now uses `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Unminute` (see docs/PACKAGING.md), so the earlier version's Win32 app still counts as installed: supersede it with the option to uninstall the previous version, rather than deploying its uninstall separately (two assignments run in no set order, and the earlier uninstaller removes the new Start menu shortcut if it runs second). Have users finish the steps above in the earlier version (hand off, cleanup, holds, token) before that uninstall runs, and add `-Managed` to this release's install command if the earlier one used it, as the setting does not carry over (#136).
- **Safer uninstall.** The installer and the uninstaller refuse an install folder that is, holds or sits inside `%LOCALAPPDATA%\Unminute`, an empty one, or one starting with `\\` or `//`. The uninstaller removes only what the installer put in its folder, removes nothing if the folder holds anything else or is not an Unminute install, and keeps the shortcut and uninstall entry when the entry names another folder, so a mistyped or older install folder cannot take the real install's shortcut and uninstall entry (#136).
