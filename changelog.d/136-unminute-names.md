- **One name everywhere: Unminute.** The app's data is now in `%LOCALAPPDATA%\Unminute` (`workspace` and `models`), it installs to `%LOCALAPPDATA%\Programs\Unminute`, and its uninstall entry, taskbar identity, saved Hugging Face token and icon use the Unminute name (#136).
- **Not an update in place from 0.4.3 or earlier.** Nothing carries over, and this version starts with an empty workspace. First, in the version you have: hand off or copy anything you still need, confirm the cleanup of finished meetings, check any holds with whoever manages them, and remove the Hugging Face token in Setup. Then uninstall it in Settings > Apps, install this version, download the models again in Setup and enter the token again. The earlier version's workspace and models stay in their own folders until you delete them. If you install this version first, Settings > Apps shows two Unminute entries, and uninstalling the earlier one afterwards removes the new Start menu shortcut: install this version again to restore it, and pin it again in place of any old taskbar pin (#136).
- **For IT: a new uninstall key.** Intune detection now uses `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\Unminute` (see docs/PACKAGING.md), so the earlier version's Win32 app still counts as installed: supersede it with the option to uninstall the previous version, or deploy its uninstall first (#136).
- **Safer uninstall.** The installer refuses an install folder that is, holds or sits inside `%LOCALAPPDATA%\Unminute`, or a path starting with `\\`. The uninstaller makes the same overlap check, and removes only what the installer put in its folder: if the folder holds anything else, it removes nothing (#136).
