Security hardening (#111, phase C):

- **A content-free audit log of how meetings are handled.** Unminute now records when each meeting is imported or recorded (with the recording confirmation), reviewed, handed off (copied, saved or opened in the assistant), held, cleaned up or discarded, and when watched folders and permission to delete originals change. Each entry holds the kind of action, the time, the app's own reference numbers and counts only: never titles, names, text, file or folder names, or hold reasons. The log is kept in `workspace\audit\`, at most 16 MB, and each entry carries a fingerprint of the one before, so an edited or removed entry shows. The user guide has a short section, "What Unminute records about your work".
- **For IT: a copy in the Windows event log.** A fingerprint of each entry (not its reference numbers) is written to the Windows Application log under the source `Unminute`, with the user's Windows account. Forwarding that log off the device makes it the stronger record. `runtime\python.exe -I -B -m workspace --verify-audit` (as the signed-in user) checks the chain, and with `--event-log` or `--event-log-file` compares it with the event log copy. `--status` adds `audit_seq`. See `docs/PACKAGING.md`.
