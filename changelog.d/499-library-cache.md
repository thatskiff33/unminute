- **Nothing left behind in your profile by speaker identification.** The speaker identification libraries load matplotlib, which saved a list of the computer's fonts in a `matplotlib` folder in your local app data, where it stayed after Unminute closed or was removed. Unminute now gives it a temporary folder of its own, removed when the app closes (or, after a crash, the next time Unminute processes a meeting); the self-test before an update does the same. The list named fonts only, never meeting content. Release evidence also now explains one file it does not control: the Intel graphics driver's shader cache (`LocalLow\Intel\ShaderCache`), which the driver writes when the window draws and which holds compiled graphics programs, not content; it was added under the owner's decision DEC-057 with its own independent review (#499).
