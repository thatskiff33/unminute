# Decisions log

The decisions the user and the owner have made for this repository, so the rules can say what
they are and this page can say who decided them, when and where. Each entry has an ID, the date
in New Zealand time, who decided (in the source's words), the decision in brief, the comment or
pull request that records it, and what it replaced.

- A doc or `AGENTS.md` that mentions a decision cites its ID right after the mention, for example
  "the owner's decision DEC-031". `tests/test_decisions.py` checks every mention in the Markdown
  docs and that every cited ID is listed here.
- A new decision gets the next free ID, in the pull request that first relies on it. IDs are never
  reused or renumbered, so a later entry can carry an earlier date.
- A decision that changes an earlier one names it under "Supersedes", and the earlier entry stays.
- The source is the record of the decision. This page summarises it; where the two differ, the
  source wins and this page is corrected.
