                This app transcribes on this computer. It needs a speech model, and optionally a speaker identification model, downloaded once. Downloads happen only here, when you choose; each file is checked against a published checksum before it is used.

                        Help and shortcuts

                        How a meeting moves through Unminute

                        1. 1TranscribeRecord or import. Unminute transcribes, then works out who spoke.
                        2. 2ReviewPlay passages, fix words, name speakers, then confirm. The audio is then removed.
                        3. 3Hand offCopy the reviewed text to draft the final document outside the app.
                        4. 4Clean upConfirm the final document is saved. The transcript is removed; a receipt stays.

                        Name speakers

                        Listen to each speaker's examples and give them a name. Names are for this meeting only and are removed with the transcript at cleanup. To move one passage to a different speaker, select its speaker label in the transcript.

                        Hand off the reviewed transcript

                        Copy or save the prompt and transcript, then use them in your organisation's approved AI assistant. The app sends nothing anywhere. Check you are using your business account, and review everything the assistant produces before you rely on it.

                        Leave out passages or redact words (this handoff only)

                        These change only what is copied or saved. The reviewed transcript stays as it is.

                        Passages to leave out:

                          You changed what is left out or redacted. Select Apply to update the preview before copying or saving.

                          This handoff is long. It is never shortened, but some assistants cut off long pasted text: prefer Save Markdown, attach the file and use Copy prompt only.
